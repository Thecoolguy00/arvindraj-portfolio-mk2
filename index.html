CyberStrike v2

Architected a dual-planner autonomous WAPT framework using LangGraph with a strategic phase manager and tactical task generator, implementing adaptive plan-execute-replan loops across recon, enumeration, vuln analysis, exploitation, and reporting phases. Built a persistent LLM-based vulnerability advisor that nudges the tactical planner toward unchecked high-value attack surface (XSS, SSTI, CORS, Git exposure) every cycle across all phases, enforcing breadth-first coverage. Engineered a dependency-aware parallel executor using asyncio.gather with topological task ordering, reducing per-phase cycle count by 3-5x. Built specialised agents for Nmap, HTTP inspection, directory enumeration, XSS validation, and custom scripting, backed by MCP execution layers with shell injection prevention, scoped filesystem protections, and async background task infrastructure. Validated attack techniques and agent behavior against real-world scenarios using TryHackMe lab environments.
